# rdepa29/ricer
My custom windows ricing tool, uses configs from [rdepa29/config](https://github.com/rdepa29/config)

## Usage
After installing *ricer*, run `ricer install` to install packages and apply configs <br>
  >`ricer install <selection>` installs chosen apps only, e.g. `1,3`, `1-4`, `2-`, `-3`, `...` for all, `^2` to exclude, or app names <br>
`ricer update` will update *ricer* and its packages <br>
`ricer config` will configure the packages (~/.config) <br>
